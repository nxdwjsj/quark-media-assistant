# 夸克影视助手 quark-app

**资源站搜索 → 一键转存到自己的夸克网盘 → 本机代理播放**

全部在本机运行；视频流只走本机代理与夸克 CDN，不经过任何第三方服务器。

> 这是一个自用的个人项目：从零跑通「搜索—转存—播放」整条链路，
> 开发过程以 Agent（Claude Code、Codex 等）驱动完成，重点是把它做成每天真正能用起来的东西。

## 它解决什么问题

想在网盘里看片，通常要在资源站、网盘 App、播放器之间来回跳转：
资源站搜出分享链接 → 复制 → 打开网盘 → 转存 → 在 App 里播放，
一旦要换设备或续播就更麻烦。这个工具把这几步合成一条流程：

1. **搜索**：输入片名，从资源站拿回分享链接列表，支持模糊 / 适中 / 精准三档匹配；
2. **转存**：点一下自动新建以关键词命名的文件夹，整包转存进自己的网盘；
3. **播放**：内置播放器直接播放网盘里的视频，不跳转 App、不先下载到本地。

## 功能

- **首页即网盘**：双击文件夹进入、双击视频播放，面包屑可回跳
- **最近播放 / 续播**：保留 30 天内最近 6 条，点「续播」从上次进度接着看
- **播放器可关闭**：关闭时先记进度再停播，清空播放器与高亮，影院区随之退出
- **播放失败兜底**：取地址失败或 HLS 致命错误时，中途出错误卡并提供「重试」
- **删除走自绘确认框**：删除进网盘回收站，可恢复

## 技术要点

| 模块 | 做法 |
|---|---|
| 本地服务 | Node.js 起一个只监听 `127.0.0.1` 的 HTTP 服务，浏览器当客户端 |
| 认证 | 复用网页版登录态（Cookie `__uid` + `__puus`），失效时界面提示重新登录 |
| 转存 | 走网盘网页接口完成新建文件夹与转存，不依赖官方 CLI |
| 播放 | 服务端代理取直链并处理 Range，前端用 HLS 播放；字幕单独处理 |
| 端口 | 端口被系统占用时自动顺延（8787 → 8888 / 8890 / 8791 / 8788） |

## 运行

```powershell
# 安装依赖
npm install

# 启动本地服务
node src\server.mjs
```

然后打开 <http://127.0.0.1:8787>（端口被占用时看启动日志）。
